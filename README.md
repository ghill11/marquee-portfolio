# Dr. Geoffrey Hill: Marquee Portfolio

This repository hosts Dr. Geoffrey Hill's portfolio of academic work from the
University of Central Arkansas, published through the Marquee plugin.

**Portfolio URL:** https://ghill11.github.io/marquee-portfolio/

## How this is built

The site is generated with [Jekyll](https://jekyllrb.com) using the
[Minimal Mistakes](https://mmistakes.github.io/minimal-mistakes/) theme
(via `remote_theme`). GitHub Pages builds it automatically on every push.

Most files in this repository are **regenerated on every publish from
Marquee**. Hand-edits will be overwritten the next time you publish from
the Marquee web app. After graduation, see `MAINTENANCE.md` for
instructions on maintaining the site yourself.

## Layout

- `_config.yml`: site configuration
- `index.md`: landing page
- `_artifacts/`: one Markdown file per artifact, rendered at `/artifacts/<slug>/`
- `assets/covers/`: auto-generated 1200x630 PNG cover images for each artifact
- `_sass/minimal-mistakes/skins/_uca.scss`: UCA-purple skin
